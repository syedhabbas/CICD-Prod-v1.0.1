
In this project we will create CICD Pipeline with Jenkins.

Steps Description

    -   We will spin 2 EC2 virtual machines on Amazon Cloud., 
        Master node and Slave node Jenkins

    -   We will install Java JDK latest version
        java --version | check java version
        javac --version | check java compiler
        # sudo apt search openjdk*
        # sudo apt update
        # sudo apt install openjdk-25-jdk 
    -   If we are running an older java version, ubuntu may not use new version & we have 
        to switch to new version by using alternative tool 
        # sudo update-alternatives --config java 
        # sudo update-alternatives --config javac
        # java --version
        # javac --version 

    -   We will install Jenkins on Master node only from Jenkins official website
