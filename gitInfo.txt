
Info regarding git, when we create a new git repository on Git Hub.

Create a new repository on the command line

echo "# CICD-Prod-v1.0.1" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/syedhabbas/CICD-Prod-v1.0.1.git
git push -u origin main


Push an existing repository from the command line

git remote add origin https://github.com/syedhabbas/CICD-Prod-v1.0.1.git
git branch -M main
git push -u origin main
